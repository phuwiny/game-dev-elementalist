# Design — ภูตตัวที่ 5 "Inkle" (งานศิลป์วันเกิด)

วันที่: 2026-11-22 · ขนาดงาน: เล็ก (เอกสารอย่างเดียว ไม่มีโค้ด)

## เจตนา

ผู้ใช้อยากได้ภูตตัวที่ 5 ในธีมวันเกิดและธีมของตัวเอง เก็บไว้เป็นงานศิลป์ส่วนตัวก่อน ถ้าชอบค่อยใส่ในเกมเป็น easter egg ภายหลัง

## ตัวละคร (ผู้ใช้เลือกแบบ B)

- **ชื่อ:** Inkle — ภูตแห่งหมึกและเส้นสาย
- **ลักษณะ:** หยดหมึกสีม่วงทรงกลม หางเป็นปลายพู่กัน สวมหมวกปาร์ตี้ทรงกรวยเอียง บนตัวมีรอยสีเลอะเป็นสีประจำธาตุทั้ง 4
- **นิสัย:** ช่างฝัน สมาธิสั้น เห็นอะไรก็อยากวาด แต่วาดจนเสร็จทุกครั้ง
- **Idle:** ใช้หางวาดวงเล็กๆ กลางอากาศ แล้วเส้นค่อยๆ จางหายไป
- **สีหลัก:** `#6b3fa0` (Spirit magic) เป็นสีเดียวใน master palette ที่ไม่ใช่สีประจำธาตุไหน
- **Easter egg (ผู้ใช้เลือกเงื่อนไขของแบบ A):** ปรากฏตัวข้าง Aclaire ที่หน้า Title เฉพาะวันที่ 22 พ.ย. ตามวันที่ในเครื่องผู้เล่น **ยังไม่ทำในรอบนี้**

## แนวทางที่พิจารณา

1. ผู้ใช้วาดเองจาก character sheet
2. Codex วาด concept art จาก character sheet
3. Claude ทำ pixel mockup 32×32 ไว้ดูทรงและสี (ใช้แทนภาพจริงไม่ได้)

**ผู้ใช้เลือกทั้ง 1 และ 2** ส่วนทาง 3 ไม่ได้เลือก จึงไม่ทำ

## สิ่งที่จะทำ

1. **Character sheet** `docs/spirits/inkle.md` (ภาษาไทย) ประกอบด้วย ลักษณะ สัดส่วน, palette ที่เสนอ (hex), นิสัย, ท่า idle, expression 3 แบบ (ปกติ / ตั้งใจวาด / ดีใจ) และ size reference เทียบกับภูต 4 ตนเดิม
2. **หัวข้อ 8.2 ใน `ART_HANDOFF.md`** สั่งงาน Codex ให้วาด concept art ลง `art/concept/2026-11-22_inkle_concept_source.png` เป็นภาพลักษณะเดียวกับ `spirits_sheet.png` (ภาพเต็มตัว + expression 3 แบบ) ระบุชัดว่าเป็นงานศิลป์ส่วนตัวที่ยังไม่ใช้ในเกม
3. แจ้งในหัวข้อ "งานถัดไป" ของ `docs/STATUS.md`

## ข้อจำกัดและสิ่งที่ห้ามทำ (anti-goals)

- ห้ามแตะ `public/assets/`, `src/assets/manifest.ts`, master palette และระบบ 4 ธาตุ (ปุ่ม 1–4, HUD, Spirit Knight, บอส) เพราะยังไม่ได้ตัดสินใจใส่เกม
- Claude แก้ `art/` ไม่ได้ ภาพที่ผู้ใช้วาดเสร็จ ผู้ใช้วางเองที่ `art/reference/spirit_ink_inkle.jpg` (ตั้งชื่อตามแบบภูต 4 ตนเดิม)

## การตัดสินใจของ Claude (ผู้ใช้แก้ได้)

- **ลำดับงาน:** ผู้ใช้กับ Codex ทำพร้อมกันจาก character sheet เดียวกัน ถ้าภาพของผู้ใช้เข้า `art/reference/` ก่อน Codex ต้องยึดภาพนั้น (ตามกติกาใน `AGENTS.md`)
- **Palette ที่เสนอ:** ramp สีม่วง `#3b1f5e` / `#6b3fa0` / `#9b6fd0` / `#d2b8f0` + ขอบหมวก/ประกาย `#ffd36b` + รอยสีธาตุ `#e8572a` `#2f9ed9` `#48c9a0` `#a8772f` สีม่วงทั้ง 3 สีที่เพิ่มยังไม่เข้า master palette จนกว่าจะตัดสินใจใส่เกม
- **ขนาดในเกม (ถ้าทำภายหลัง):** ใช้ 64×64 density 2 เหมือน Valvaliz/Eathy (atlas `spirits_hd`)
