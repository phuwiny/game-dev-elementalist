# Character Sheet — Inkle ภูตแห่งหมึกและเส้นสาย

สถานะ: **งานศิลป์ส่วนตัว ยังไม่ใช้ในเกม** · สร้าง 2026-11-22 (วันเกิดผู้ใช้) · design: `docs/superpowers/specs/2026-11-22-inkle-spirit-design.md`

## 1. ภาพรวม

Inkle เป็นภูตตัวที่ 5 ไม่มีธาตุของตัวเอง เกิดจากหยดหมึกที่ใช้วาดภูตทั้ง 4 ตน บนตัวจึงมีรอยสีของทุกธาตุเลอะอยู่ สวมหมวกปาร์ตี้ตลอดเวลาเพราะถือว่าทุกวันที่ได้วาดรูปเป็นวันพิเศษ

| หัวข้อ | รายละเอียด |
|---|---|
| ชื่อ / key | Inkle / `inkle` |
| ประเภท | ภูตพิเศษ ไม่มีธาตุ ไม่มีสกิลต่อสู้ |
| สีประจำตัว | `#6b3fa0` (Spirit magic) |
| คำสั้นๆ | ช่างฝัน วาดไม่หยุด วาดจนเสร็จทุกครั้ง |

## 2. ลักษณะและสัดส่วน

- **ตัว:** หยดหมึกทรงกลม ก้นกว้างกว่าหัวเล็กน้อยเหมือนหยดที่เพิ่งตกถึงพื้น ผิวมันวาว มีไฮไลต์โค้งที่มุมบนซ้าย 1 จุด (แสงมาจากซ้ายบนตามมาตรฐานของเกม)
- **ตา:** ตากลมโตสีเข้ม `#0f0b1a` มีจุดสะท้อนแสงสีขาว `#f2efe6` 2 จุด (ใหญ่ 1 เล็ก 1) ห่างกันพอประมาณ ดูเหม่อๆ ช่างฝัน
- **ปาก:** เส้นยิ้มเล็กๆ บางครั้งแลบลิ้นออกมาข้างหนึ่งตอนตั้งใจวาด
- **หาง:** งอกจากด้านหลังล่าง โค้งขึ้นเป็นรูปตัว S ปลายเป็นพู่กันขนนุ่ม ปลายพู่จุ่มหมึกสีม่วงเข้ม ความยาวหางเท่ากับความกว้างตัวโดยประมาณ
- **หมวกปาร์ตี้:** ทรงกรวยสีม่วงอ่อน `#d2b8f0` คาดลายทางทแยงสีทอง `#ffd36b` มีพู่กลมสีทองที่ปลาย สวมเอียงไปทางขวาประมาณ 15–20° สูงราว 1/3 ของความสูงทั้งหมด
- **รอยสี 4 ธาตุ:** จุดสีเล็กๆ 4 จุดกระจายบนตัว ขนาดไม่เท่ากัน ไม่เรียงเป็นแถว ได้แก่ ส้มไฟที่แก้มซ้าย, ฟ้าน้ำที่ท้อง, เขียวลมที่ข้างขวา และน้ำตาลดินที่ก้น
- **ขอบ:** outline `#0f0b1a` เหมือนภูตตนอื่น

สัดส่วนรวม (สูง : กว้าง) ประมาณ 4 : 3 เมื่อรวมหมวก

```
        *          <- พู่ทอง
       /\
      ///\         <- หมวกปาร์ตี้เอียงขวา
    .------.
   (  o  o  )  ~~~ <- หางพู่กันโค้ง S
   ( ·  ‿   ·)  //
    `------'--'
```

## 4. นิสัย

- **ช่างฝัน:** ชอบมองท้องฟ้าแล้วเห็นเมฆเป็นรูปต่างๆ
- **สมาธิสั้น:** เห็นอะไรก็อยากวาด กำลังวาดอย่างหนึ่งอยู่ก็หันไปสนใจอีกอย่าง
- **วาดจนเสร็จทุกครั้ง:** ถึงจะวอกแวก สุดท้ายก็กลับมาวาดทุกภาพจนจบ เป็นข้อดีที่เพื่อนๆ นับถือ
- **ความสัมพันธ์:** เป็นคนวาดภาพของภูตทั้ง 4 ตน Burnil ใจร้อนจนไม่ยอมนั่งนิ่งเป็นแบบ, Wata ขอให้วาดตัวเองหลายรอบ, Valvaliz อายจนซ่อนหน้าหลังปีก, Eathy คอยติว่าวาดสัดส่วนผิด

## 5. ท่าทาง

**Idle (ถ้าทำ animation: 6 frame, 8 fps, loop):** ลอยขึ้นลงเบาๆ ใช้หางวาดวงกลมเล็กๆ กลางอากาศ 1 วง เส้นหมึกที่วาดค่อยๆ จางหายไปใน 2–3 frame สุดท้าย

**Expression 3 แบบ**

| แบบ | รายละเอียด |
|---|---|
| ปกติ | ตาโตเหม่อมองขึ้นข้างบนนิดๆ ยิ้มบาง หมวกเอียงขวา |
| ตั้งใจวาด | ตาหรี่ คิ้ว (ถ้ามี) ขมวดนิดหนึ่ง แลบลิ้นออกข้างหนึ่ง หางยกขึ้นพร้อมวาด ตัวเอนไปข้างหน้า |
| ดีใจ | ตาปิดโค้งเป็นรูป ^ ^ ปากเปิดกว้าง หมวกเด้งลอยขึ้นจากหัว มีหยดหมึกเล็กๆ กระเด็นออกมา 2–3 หยด |

## 6. เทียบขนาดกับภูตเดิม

- ในเกมภูตทุกตนแสดงที่ 32×32 ถ้าใส่ Inkle ในเกมภายหลัง ให้ทำแบบ 64×64 density 2 เหมือน Valvaliz และ Eathy (atlas `spirits_hd`)
- ตัวหยดหมึก (ไม่รวมหมวก) มีขนาดเท่ากับ Wata โดยประมาณ หมวกกับหางยื่นออกนอกกรอบตัวได้ แต่ต้องไม่เกินกรอบ frame
